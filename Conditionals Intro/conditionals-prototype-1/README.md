# Conditionals Prototype Project 1 - Shy Creature

Alycia Malonga 

[View this project online](http://127.0.0.1:5500/Conditionals%20Intro/conditionals-prototype-1/index.html)

## Description
Shy Creature is an interactive sketch about a creature that gets nervous around people. It starts as a black circle on a lilac purple background, and its mood changes depending on how close the mouse is. When the mouse is far away, it turns green and looks happy. When it's at a medium distance, it turns black, and when the mouse gets too close, it turns blue and tries to run away. The creature can't leave the canvas, so if you chase it into a corner, it gets stuck with nowhere to go. I wanted to make something simple but fun that shows how a creature can react differently depending on how you interact with it.
