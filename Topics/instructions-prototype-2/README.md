Alycia Malonga

[View this project online](https://editor.p5js.org/AlyMal17/sketches/EOGSz0UR0)

## Description

This is just a static drawing of an ice cream cone with three scoops, made out of basic p5 shapes like triangles, circles, arcs. Each scoop has a little smiley face, and there's a scalloped border between the cone and the scoops. Nothing to click or interact with, just meant to be a fun, cartoony image to look at.
