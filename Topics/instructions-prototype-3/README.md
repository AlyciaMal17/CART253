# Prototype Project 3

Alycia Malonga

[View this project online](https://editor.p5js.org/AlyMal17/sketches/Ow7MXB7Is)

## Description

A static minion made from basic p5 shapes using ellipses, rectangles, and arcs layered together for the body, goggles, overalls, and smile. Just a fun character to look at, no interaction are needed.
