#  Events Prototype 3 - The Barking Doorbell

Alycia Malonga

[View this project online](http://127.0.0.1:5500/Events%20Intro/events-prototype-3/index.html)

## Description
The Barking Doorbell is an interactive sketch of a brown door with a doorbell beside it. When you click the red button, a dog barks, the door opens to show a yellow room, and the light above the door turns on. After two seconds, the door closes by itself and the light turns off again. I wanted to make something simple but funny, with a little surprise since you expect a normal doorbell but get a dog barking instead. It also shows how adding sound and a timer can make basic shapes feel more alive.
