# Functions Protoype Project 2 - Buzzing Flies

Alycia Malonga

[View this project online](http://127.0.0.1:5500/Functions%20Intro/Functions-Prototype-2/index.html)

## Description

Buzzing Flies is a small sketch with four silly flies that get angry when you get too close to them. They start off smiling and barely moving, but when the mouse gets near, they turn red, look angry, and start shaking more. I wanted the sketch to feel funny and a little bit annoying, and I used functions to create and control all four flies without repeating the same code.
