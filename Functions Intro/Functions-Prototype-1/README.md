# Functions Protoype Project 1 - Balloon Stand

Alycia Malonga

[View this project online](http://127.0.0.1:5500/Functions%20Intro/Functions-Prototype-1/index.html)

## Description

Balloon Stand is a small carnival game with five coloured balloons. Each balloon takes three clicks to pop, growing a little after the first click and turning orange after the second as a warning. I wanted the game to feel fun and playful, but with a little tension, like a real carnival game. I also used functions to create and control all five balloons without repeating the same code.
