# Variable Prototype Project - The Beating Heart

Alycia Malonga

[View this project online](http://127.0.0.1:5500/Variables%20Intro/variables-prototype-2/index.html)

## Description
Heartbeat is an interactive sketch of a heart that beats on its own against a dark background. By moving the mouse left and right, you can change the heart's size and colour, going from a small, soft pink heart to a bigger, brighter red one. The heart keeps pulsing even when the mouse isn't moving, making it feel like it's alive. I wanted to create something simple but expressive, showing how changing the size and colour of a shape can give it different emotions and make it feel more alive.
