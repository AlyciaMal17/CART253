# Arrays Prototype Project 2 - Candy Catcher

Alycia Malonga

[View this project online](http://127.0.0.1:5500/Arrays_Intro/Arrays-Prototype-2/index.html)

## Description

Candy Catcher is a small sketch about catching as many candies as you can before time runs out. Colourful wrapped candies fall from the top of a pink background, each with its own colour, size and speed. You click on them to catch them before they disappear, while a timer counts down from 45 seconds. As the time gets closer to zero, the candies start falling faster and appearing more often, making it harder to keep up. Once the time runs out, the sketch shows your final score. I wanted it to feel fun and sweet at first, but slowly become more chaotic as the game gets faster. The idea is to see how many candies you can catch and maybe try again to beat your score. I also wanted to experiment with using an array and a loop to manage multiple candies at once, while using the time left to control how quickly the game gets harder.
